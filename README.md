## 🎯 Overview

**Momentum** is an AI-powered, on-chain habit tracker specifically designed for traders who want to build discipline and consistency in their trading journey. Built on the Internet Computer Protocol (ICP) blockchain, Momentum transforms trading discipline into a measurable, social, and gamified experience.

### The Problem

Most traders fail not because of poor strategy, but due to lack of discipline and consistency. Traditional habit trackers don't understand trading-specific needs, and there's no verifiable proof of discipline that traders can showcase to communities or exchanges.

### Our Solution

Momentum leverages ICP's unique capabilities—scalable canisters, Chain Fusion, and AI integration—to help traders:
- Track trading-specific habits (journaling, risk management, market reviews)
- Build and maintain streaks with on-chain verification
- Earn NFT badges as proof of discipline
- Receive AI-powered coaching and nudges
- Build verifiable reputation in trading communities

## ✨ Key Features (MVP)

### 1. **Trading Habit Creation**
- Create custom trading habits (journaling, backtesting, market analysis)
- Set frequency (daily/weekly) and target streak goals
- All data stored securely in ICP canisters

### 2. **Streak Tracking**
- Daily/weekly check-in system
- Real-time streak counter with visual feedback
- Automatic reset on missed check-ins
- Week-view calendar showing progress

### 3. **NFT Proof of Discipline**
- Earn NFT badges for completed streaks
- Unique metadata: habit type, streak length, timestamp
- Portable reputation across Web3 trading communities

### 4. **AI Coaching (Lite)**
- Motivational messages based on progress
- Trading-focused encouragement
- Streak milestone celebrations

### 5. **Gamification System**
- XP (Experience Points) for completed habits
- Level progression system
- NFT collection gallery
- Community leaderboards

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- DFX SDK (latest version)
- Mops (Motoko package manager)
- Internet Identity wallet

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/ICP-Momentum/momentum.git
cd momentum
```

2. **Install dependencies**
```bash
npm install
```

3. **Start the local ICP replica**
```bash
dfx start --clean --background
```

4. **Deploy canisters**
```bash
dfx deploy
```

5. **Start the frontend**
```bash
npm start
```

6. **Access the application**
```
Local: http://localhost:3000
Live: https://yfmxz-kyaaa-aaaaj-a2gqq-cai.icp0.io/
```
